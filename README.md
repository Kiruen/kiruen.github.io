# Kiruen 的小站

这是一个不需要安装依赖、构建工具或数据库的静态网站，由 GitHub Pages 发布。

- 首页：`index.html`
- 阅读示例：`book/index.html`
- 页面样式：`style.css`

在 GitHub 网页上打开对应文件，点击铅笔图标编辑并提交，或在本地修改后推送到 `main` 分支。GitHub Pages 构建完成后，网站会自动更新。

这里的“小书”是一个可替换文字的简单示例，不是 GitBook 服务。以后可以按需要换成 GitBook，或使用 VitePress 等工具生成带目录的文档网站。

本仓库和发布的网站都是公开的，请只放适合公开分享的内容。
